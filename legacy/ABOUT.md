# Legacy prototype (archived)

This folder holds the original Cypherpunk Legacy prototype: seven standalone
HTML pages exploring cryptography concepts (grandpa's room, BIP39, encryption
demo, Taproot explorer, Cyberspace/Lagrange, algorithm capture, lattice
cryptanalysis).

It is preserved for reference. The cryptography in these pages was illustrative
rather than real. The rewrite at the repository root (`v2` branch) reimplements
everything with genuine, unit-tested cryptography and a single game engine.

To view the old prototype: open `legacy/index.html` in a browser.
