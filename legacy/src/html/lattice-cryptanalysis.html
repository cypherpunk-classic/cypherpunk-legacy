🧮 What is a Lattice?

A lattice is a regular arrangement of points in n-dimensional space, formed by integer linear combinations of basis vectors.

L = {Σ zibi : zi ∈ ℤ}

Think of it as an infinite grid of points extending in all directions!

Lattice Basics: Vectors & Basis

📐 Basis Vectors

A lattice is defined by its basis vectors. For a 2D lattice:

b1 = (x1, y1), b2 = (x2, y2)

Any lattice point can be written as: z1b1 + z2b2 where z1, z2 are integers.

Shortest Vector Problem (SVP)

⚠️ The Hard Problem

The Shortest Vector Problem (SVP) asks:

Find the shortest non-zero vector v in lattice L

This problem is NP-hard and forms the basis of lattice-based cryptography!

LLL Algorithm: Lattice Reduction

🔬 The Lenstra-Lenstra-Lovász Algorithm

The LLL algorithm finds a "reduced" basis - vectors that are shorter and more orthogonal.

Algorithm Steps:

  1. Gram-Schmidt Orthogonalization: Compute orthogonal projection
  2. Size Reduction: Make basis coefficients small
  3. Lovász Condition: Check if basis is reduced
  4. Swap if needed: Swap vectors if condition fails
  5. Repeat: Until all vectors satisfy conditions
